# CourseRec 使用指南

本文件說明 CourseRec 的安裝、錄影、書籤、快拍、檔案庫、快剪與匯出流程。若需開發或建置資訊，請參閱 [系統架構與技術文件](ARCHITECTURE.md) 與 [建置與發行](BUILD.md)。

---

## 1. 安裝與啟動

1. 由 [GitHub Releases](https://github.com/mark216tw/CourseRec/releases) 下載符合系統架構的 zip：
   - x64：`CourseRec-<版本>-win-x64-framework-dependent.zip`
   - ARM64：`CourseRec-<版本>-win-arm64-framework-dependent.zip`
2. 安裝 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（非 Self-Contained 版本必要）。
3. 將 zip 解壓縮到可寫入的資料夾，例如 `C:\Apps\CourseRec`。
4. 執行 `Com.VibeCode.CourseRec.exe`。程式採單一實例設計，重複啟動會帶回既有視窗。

第一次啟動會建立 `%AppData%\CourseRec\settings.json` 與日誌資料夾，並使用預設輸出資料夾。若 Windows SmartScreen 阻擋，請選擇「更多資訊」→「仍要執行」。

> CourseRec 不提供安裝程式，也不會寫入登錄卸載項目。移除時直接刪除程式資料夾即可。

## 2. 介面導覽

左側 `NavigationView` 提供以下頁面：

| 頁面 | 用途 |
| :--- | :--- |
| 錄影工作台 | 選擇情境、來源、畫質、倒數與定時停止，開始錄影 |
| 錄影檔案庫 | 瀏覽、搜尋、排序、播放、重新命名與刪除錄影 |
| 快剪與複習 | 倍速播放、書籤跳轉、修剪、音量增強與匯出 |
| 設定 | 輸出路徑、外觀、快捷鍵、檔名前綴與預覽偏好 |
| 關於 | 版本、授權、輸出與日誌資料夾、複製版本資訊 |

設定與關於位於導覽列底部。主視窗會記住上次瀏覽頁面、視窗位置、大小與最大化狀態。

## 3. 錄影工作台

### 3.1 選擇情境

- **純聽課模式**：擷取課程／系統聲音，麥克風自動靜音並丟棄取樣，適合單向聽課。
- **參與會議模式**：同時擷取系統聲音與麥克風，兩軌以 48 kHz 混音並經 Soft Limiter 保護。

情境選擇會自動記住，下次啟動沿用。

### 3.2 選擇來源

- **全螢幕**：錄製指定螢幕；多螢幕環境請選擇正確的螢幕。
- **指定視窗**：鎖定單一視窗，即使被其他視窗覆蓋仍可錄製。
  - **只錄此視窗聲音**：於 Windows 10 Build 20348+／Windows 11 以 Process Loopback 僅擷取該程序音訊，過濾其他通知音。舊版系統會顯示降級提示並改用系統全體聲音。
  - 目標視窗最小化時，程式會重送最後一幀並提示，避免影音中斷。

音量表旁會顯示目前實際來源（目標程式／全體系統聲音／隔離降級／來源無法使用）與麥克風可用狀態。

### 3.3 畫質預設

| 預設 | 解析度 | 影格率 | 適用情境 |
| :--- | :--- | :--- | :--- |
| 簡報／會議省空間 | 1080p 上限 | 15 fps | 靜態投影片、長時間課程 |
| 標準流暢 | 原生偶數解析度 | 30 fps | 動態畫面、需要流暢度 |

兩者皆使用 H.264 High Profile、2 秒關鍵影格間距與分段式 MP4 封裝，降低斷電損毀風險。

### 3.4 倒數與定時停止

- 倒數可選 0～30 秒（含 3 秒與 5 秒間隔選項），倒數中可取消。
- 倒數期間會在目標螢幕或目標視窗中央顯示大型倒數數字，置頂、不搶焦點、穿透滑鼠點擊且不會入鏡，倒數結束或取消時自動關閉。
- 定時自動停止可選 5、10、15、20、30、60、90、120 分鐘；錄影中會顯示剩餘時間。
- 錄影期間以 `SetThreadExecutionState` 阻止系統休眠與關閉螢幕，停止或取消後恢復。

### 3.5 錄影中操作

- **暫停／繼續**：暫停時間會從輸出時間軸扣除。
- **時間書籤**：按 `Ctrl+Shift+B` 或介面按鈕，可輸入備註後按 `Enter` 新增；清單自動捲動至最新項目。
- **PNG 快拍**：按 `Ctrl+Shift+S` 擷取目前畫面，存檔並同步複製到剪貼簿，完成後以 Toast 提示。
- **迷你控制列**：由錄影工作台切換顯示、關閉程式時自動關閉；可拖曳、顯示狀態與雙音量條，預設排除於擷取畫面（`WDA_EXCLUDEFROMCAPTURE`），停止錄影後仍保持顯示待命。
- **即時預覽**：預設關閉；待機時關閉預覽會停止背景畫面擷取以節省 GPU 與記憶體。

磁碟空間不足時會提前警告；若低於安全值，程式會提示並避免繼續錄影。

## 4. 錄影檔案庫

- 清單顯示檔名、時長、大小、修改時間、書籤數與縮圖／程式圖示。
- 支援依最新、最舊、檔名、大小或時長排序，並記住上次選擇。
- 搜尋列即時比對檔名與書籤備註；`Ctrl+F` 聚焦搜尋、`Esc` 清除。
- 顯示所有錄影的合計大小與合計時長。
- 每筆錄影提供：
  - **開啟快剪**（主按鈕）
  - `…` 選單：以系統預設播放器播放、開啟檔案位置、重新命名、刪除
- 重新命名會同步更新 `.mp4` 與 `.bookmarks.json`；長檔名可懸停查看完整名稱。
- 刪除前會以 `ContentDialog` 二次確認。

## 5. 快剪與複習

### 5.1 播放

- 支援 `0.25x`、`0.5x`、`0.75x`、`1.0x`、`1.25x`、`1.5x`、`1.75x`、`2.0x` 倍速。
- 書籤清單點擊即可跳轉；支援上／下一個書籤。
- 播放器可切換全螢幕；全螢幕時按右上角「退出全螢幕」或 `Esc` 鍵返回編輯器。
- 快捷鍵：`空白鍵` 播放／暫停、方向鍵前後跳轉。
- 會記住上次載入的影片與播放位置，重新開啟程式可接續複習。

### 5.2 書籤

- 書籤可修改備註、確認後刪除，變更即時寫入 `.bookmarks.json`。
- 剪輯後匯出時，剩餘書籤時間點會自動平移校正。
- 書籤約於下一個 1.5 秒維護週期自動保存；錄影時長每 30 秒更新。

### 5.3 剪輯

- **剪輯標記時間軸**：播放器下方時間軸會標出保留範圍（綠）、剪除片段（紅）、待設定剪除點（琥珀）與書籤（藍點）；點擊或拖曳時間軸可跳轉播放位置，滑鼠移入標記會顯示對應時間。
- **頭尾保留（Trim）**：設定開始與結束時間。
- **中場刪除（Cut）**：可加入多段要移除的區間，例如中場休息。
- **人聲音量增強**：100%～200%；未變更音量時走快速剪輯通道。
- 可確認後重設頭尾範圍、剪除區間與音量增益，既有書籤會保留。
- 從錄影檔案庫開啟其他影片時，若編輯器已有影片，會先確認是否取代；確認後才切換頁面並載入。
- 載入其他影片前若有未匯出的剪輯設定，會先詢問是否放棄。

### 5.4 匯出

| 格式 | 內容 | 用途 |
| :--- | :--- | :--- |
| MP4 | 剪輯後 H.264/AAC 影片 | 課後複習、分享 |
| M4A | 48 kHz／Mono／96 kbps AAC 音訊 | NotebookLM、Whisper 等 AI 逐字稿 |

- 匯出過程顯示進度百分比與目前音量增益。
- 匯出成功後才取代正式檔案；取消或失敗會保留既有輸出。
- 完成後可直接播放剛匯出的影片，或按資料夾圖示開啟匯出目錄。
- 匯出前會確認是否套用目前剪輯設定。

## 6. 設定

| 設定項目 | 說明 |
| :--- | :--- |
| 輸出資料夾 | 儲存前會驗證可建立與可寫入 |
| 錄影檔名前綴 | 檔名格式為「前綴_日期_時間.mp4」 |
| 顯示模式 | 跟隨系統、淺色、深色 |
| 色彩主題 | 海洋藍、森林綠、暖陽橘、薰衣草紫、玫瑰粉、薄荷綠、石墨灰、可可棕、靛藍、護眼黃 |
| 預設情境／畫質／倒數／定時停止 | 下次啟動沿用 |
| 預設啟用即時預覽 | 控制待機時是否擷取畫面 |
| 排除迷你控制列擷取 | 避免控制列入鏡 |
| 預設隔離視窗音訊 | 指定視窗時預設只錄該視窗聲音 |
| 全域快捷鍵 | 可直接按鍵捕捉組合鍵，或回復預設 |

外觀設定即時儲存；其他設定於變更時寫入 `%AppData%\CourseRec\settings.json`。

## 7. 資料與隱私

- 所有錄影、快拍、書籤與設定皆儲存在本機，程式不會上傳任何內容。
- 日誌僅記錄執行狀態與錯誤，不含影音內容；可用於問題診斷。
- 清除個人資料：刪除 `%AppData%\CourseRec` 與自行建立的錄影資料夾。
- 若需回報問題，可於「關於」頁複製版本資訊，並附上日誌檔。

## 8. 疑難排解

| 症狀 | 處理方式 |
| :--- | :--- |
| 無法啟動，提示缺少 .NET | 安裝 .NET 10 Desktop Runtime 對應架構版本 |
| 啟動後沒有畫面 | 確認顯卡驅動支援 Direct3D 11；嘗試重新啟動程式 |
| 錄影沒有聲音 | 確認音量表有跳動、系統輸出裝置正確、未靜音；參與會議模式需確認麥克風權限 |
| 只錄此視窗聲音無效 | 確認系統為 Windows 10 Build 20348+ 或 Windows 11；舊版會自動降級 |
| 指定視窗錄影中斷 | 避免關閉或縮小目標視窗；縮小會重送最後一幀 |
| 匯出失敗 | 檢查磁碟空間與輸出資料夾權限；查看日誌中的錯誤代碼 |
| 全域快捷鍵無效 | 可能被其他程式占用，請在設定頁改用其他組合鍵 |
| 畫面模糊 | 使用「標準流暢」預設；省空間預設以 15 fps 與較低碼率換取檔案大小 |

日誌位置：`%AppData%\CourseRec\logs\courserec.log`（輪替檔為 `courserec.prev.log`）。
